Juno 한글 자막 미리보기

한글 줄바꿈과 강조 효과를 먼저 확인하는 브라우저 테스트. 영상이나 글꼴을 업로드하지 않아.

JUNO / KOREAN PREVIEW
0.00초

강조 타이밍은 4초짜리 시연용이야. 실제 음성 인식·단어별 싱크 결과가 아니야. 점선은 표시 안전영역이야.

Premiere 적용 안 됨
이 화면은 CSS 미리보기이며, 편집 가능한 .mogrt 파일이나 영상 렌더러가 아니야. 기존 프리미어 텍스트 쓰기 잠금은 그대로 유지돼.

한 종류부터 정확하게

선택한 글꼴이 없으면 기기의 다른 글꼴로 보일 수 있어. 글꼴 파일은 포함하지 않았어.

프리미어 문구 테스트 준비

실제로 보유한 템플릿의 ID·버전·경로를 입력해야 해. 내보내는 JSON은 원본 템플릿 미리보기와 문구 검사 준비용이며, Juno 디자인을 MOGRT로 변환하지 않아.

30,000/1,001fps · 60프레임 시작 · 90프레임 길이. 파일 존재와 버전은 프리미어에서 다시 확인해야 해.
