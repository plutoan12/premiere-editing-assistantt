# Sync Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or subagent-driven-development. TDD every behavior.

**Goal:** Build a deterministic-first synchronization engine for multicam, external audio, music playback and later re-sync workflows.

**Architecture:** Evidence extractors create normalized sync evidence. Strategy selection prefers compatible timecode, then audio correlation, then explicit manual review. All accepted results become canonical SyncGroup records with confidence and provenance.

**Tech Stack:** TypeScript, Vitest, @pea/core; FFmpeg decoding is accessed behind an AudioSampleProvider rather than embedded in matching logic.

**Spec:** `docs/superpowers/specs/2026-10-03-premiere-editing-assistant-platform-design.md`

## Tasks
### 1. Sync contracts
Create `types.ts`: SyncEvidence, SyncCandidate, SyncMember, SyncGroup, SyncConfidence, SyncReason.
Tests: reject duplicate clip IDs, empty groups, unsupported/mismatched timebases.

### 2. Timecode matcher
Create `timecode.ts`: normalize compatible timecode to exact Core media time; compute offsets against reference/earliest member.
Tests: 24, 23.976, 29.97 DF/NDF identity, missing TC, incompatible rate metadata.
Rule: never convert DF/NDF or rates silently.

### 3. Audio sample boundary
Create `audio-provider.ts`: AudioSampleProvider returns mono normalized sample windows and sample-rate metadata.
No FFmpeg process calls inside matcher.

### 4. Waveform correlation
Create `audio-correlation.ts`: coarse-to-fine normalized cross-correlation; configurable search window; score + best offset + second-best margin.
Tests: known synthetic offsets, silence, low-SNR ambiguity, repeated periodic signal ambiguity.
Rule: ambiguous result is review-required, not a fake exact sync.

### 5. Strategy/orchestrator
Create `strategy.ts`, `sync.ts`: timecode → audio → manual. Record evidence used and confidence.
Tests: deterministic fallback ordering and cancellation propagation.

### 6. Multicam grouping
Create `multicam.ts`: build groups from compatible overlapping clips; preserve camera/source identity.
Tests: 2/3/8 camera fixtures, disconnected groups, external recorder member.

### 7. Music/playback sync
Create `playback.ts`: align takes against reference playback/master audio; support slate/head silence.
Tests: multiple takes against one reference and truncated take.

### 8. Re-sync
Create `resync.ts`: map prior timed artifacts to revised sequence using stable clip identity + source ranges; return mapped/unmapped/conflicted sets.
Tests: ripple edit, trimmed head, reordered clip, deleted clip, duplicated source segment.

### 9. Public API
Split current `index.ts` into focused files and export stable API.
Run `pnpm --filter @pea/sync test && pnpm --filter @pea/sync typecheck`.

## Completion criteria
- Known synthetic offsets are recovered within one analysis sample/frame-equivalent tolerance.
- Ambiguity is surfaced.
- No Premiere dependency.
- No source media mutation.
- Every accepted sync has strategy, confidence and provenance.
