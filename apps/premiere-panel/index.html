PEA Sync LOCAL · 0.2.0

테스트 프로젝트 복사본에서 사용해. 원본 파일이나 기존 편집 시퀀스는 변경하지 않아.

1. Helper 세션 폴더 연결

먼저 start-helper.command를 실행하고, 터미널에 표시된 session 폴더를 선택해.

2. Premiere 선택 클립 읽기

기준 시퀀스를 열고 프로젝트 패널에서 원본 클립 2~16개를 선택해.

기준 음원 / 카메라 분석 방식 오디오 싱크플레이백 / 마스터 음원
분석 시작 (초)
분석 길이 (초, 최대 32)

분석용 8 kHz 모노 변환. 선택한 구간에 공통 소리가 있어야 해. 장시간 드리프트는 보정하지 않아.

3. 싱크 분석취소

Premiere 런타임 연결 중…

새 Sync 시퀀스 이름 4. Dry Run 미리보기 

    별도 저장한 테스트 프로젝트 복사본임을 확인했어.
    5. 승인한 배치 Apply
    검증 결과 저장
    
Apply는 새 시퀀스를 만들어 클립을 배치해. 실패 시 자동 롤백을 약속하지 않아. 결과 시퀀스를 직접 재생해서 확인해.
