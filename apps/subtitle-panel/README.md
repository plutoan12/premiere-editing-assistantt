# Subtitle UXP 개발 패널

원본의 전사·대사 검색과 미리 렌더한 편집본의 자막 제작을 같은 문서 라이브러리에서 처리합니다. 기존 `@pea/transcript`, `@pea/premiere-transcript`, `@pea/helper-protocol`과 로컬 Helper를 재사용합니다.

## 빌드와 실행

저장소 루트에서 실행합니다.

```sh
pnpm --filter @pea/subtitle-panel test
pnpm --filter @pea/subtitle-panel typecheck
pnpm --filter @pea/subtitle-panel build
```

빌드는 `dist/premiere-subtitle/`에 `manifest.json`, `index.html`, `style.css`, `main.js`, 소스맵을 준비합니다. Adobe UXP Developer Tool에서 해당 manifest를 추가하고 Premiere Pro 25.6 이상에 개발용으로 로드합니다. 패널 ID는 `pea-subtitle`, 플러그인 ID는 `com.plutoan12.premiere-editing-assistant.subtitle`입니다. 기존 패널과 별도 ID를 사용합니다.

이 산출물은 개발 패널이며, 서명된 CCX 설치 파일이 아닙니다. 빌드·호스트 대역 테스트는 실제 Premiere 로드·사용 검증을 대신하지 않습니다.

## 입력

### 원본 · 전사와 대사 검색

1. 작업 대상을 **원본**으로 선택합니다.
2. Premiere 프로젝트 패널에서 원본 클립 하나를 선택한 뒤 **선택 클립의 기존 전사 읽기**를 누릅니다.
3. 전사가 없으면 Premiere의 기본 전사 기능을 사용하거나, **Premiere에서 새 전사**를 눌러 생성을 허용할 수 있습니다. 이미 전사가 있는 경우 기존 결과를 우선 사용합니다.

시퀀스 선택과 안정적인 프로젝트 ID를 확인할 수 없는 입력은 거부합니다. 읽기 시작 시 클립을 고정하고 전사 도중 프로젝트나 원본 경로가 바뀌면 결과를 추가하지 않습니다. Adobe 원본 JSON은 문서의 `rawSourceJSON`으로 보존됩니다.

로컬 파일을 직접 전사할 수도 있습니다. 실행 중인 기존 Helper의 bootstrap JSON을 선택한 뒤 **파일 선택 후 로컬 전사**를 누릅니다. Helper에는 허용된 원본 경로와 로컬 FFmpeg·whisper.cpp·모델이 사전에 설정되어 있어야 합니다. 연결은 HTTPS loopback만 허용하며 bootstrap token은 문서나 내보내기에 저장하지 않습니다. 전사 기능이 없는 Helper는 연결 완료로 처리하지 않습니다.

파일 전사는 **전체 파일의 첫 오디오 스트림**을 사용합니다. 파일의 컷 범위·다중 오디오 스트림·채널 선택 UI는 제공하지 않습니다.

### 편집본 · 자막 제작

1. Premiere에서 편집본의 대사 오디오 또는 영상을 파일로 미리 내보냅니다.
2. 작업 대상을 **편집본**으로 바꾸고 **파일 0초에 대응하는 시퀀스 시각**을 초 단위로 명시합니다. 시퀀스 처음이면 `0`을 입력합니다.
3. Helper 연결 후 렌더 파일을 선택해 전사하거나, 그 렌더 파일을 기준으로 만든 SRT/VTT를 가져옵니다.

편집 화면의 시간은 입력 파일 기준입니다. SRT/VTT를 내보낼 때만 입력한 시퀀스 시작 시각을 더합니다. 이미 시퀀스 시간으로 기록된 SRT/VTT를 가져오면 시작 시각을 `0`으로 지정해야 중복 오프셋을 피할 수 있습니다. 이 흐름은 시퀀스 자동 오디오 추출이나 원본 클립 대응 추적을 수행하지 않습니다.

SRT/VTT 가져오기는 현재 선택한 작업 대상과 시작 시각을 사용합니다. 자막 문서 JSON 열기는 파일에 저장된 대상·시간·수정 이력을 그대로 복원합니다.

## 검토·검색·저장

- 문서 라이브러리에서 원본과 편집본을 선택합니다. 검색은 열려 있는 모든 문서의 현재 수정본을 대상으로 합니다. 검색 결과를 누르면 해당 문서와 자막이 선택됩니다.
- 자막을 선택해 텍스트, 시작·끝 시각, 화자 ID를 수정하고 **수정 저장**을 누릅니다. 빈 화자 ID는 미지정으로 저장합니다.
- 분할하려면 자막 내부의 분할 시각과 앞·뒤 텍스트를 직접 입력합니다. 단어별 시간은 수정된 텍스트에서 추정하지 않습니다.
- **다음 자막과 병합**은 같은 화자의 인접하며 겹치지 않는 두 자막을 합칩니다. 두 자막 사이의 공백도 새 표시 구간에 포함됩니다.
- 시각은 소수점 9자리까지의 초 또는 `1001/30000` 같은 정확한 분수로 입력합니다. 반복소수는 분수로 표시해 편집 중 프레임 시간이 반올림되지 않게 합니다. SRT/VTT 출력은 밀리초 단위입니다.
- **JSON 저장**은 최초 전사와 수정 이력을 함께 저장합니다. **SRT/VTT 내보내기**는 현재 수정본을 저장하며 이력을 포함하지 않습니다.

라이브러리는 패널 세션 메모리에 있습니다. 수정 후 JSON으로 저장해야 패널·앱을 다시 시작해도 복원할 수 있습니다. 이미 열린 문서 ID를 다시 열면 중복으로 추가하지 않습니다. 입력 오류나 전사 실패는 기존 문서를 유지합니다. 긴 읽기·전사 작업은 취소할 수 있고 패널이 숨겨지면 대기 중인 결과를 취소합니다. 파일 저장 중에는 쓰기가 끝날 때까지 편집과 재저장을 잠급니다. 이미 Premiere에 전달된 네이티브 작업 자체는 호스트 내부에서 계속될 수 있습니다.

실제 Premiere 캡션 트랙에 적용, 타임라인 투영, 번역, 파일 원본 내용의 자동 지문 추적, 패널 재실행 시 자동 복원은 이 패널에 포함되지 않습니다. 입력 리비전은 가져온 시각으로 기록하며 파일 해시 검증으로 취급하지 않습니다.

## 확인할 호스트 동작

1. 개발 패널을 로드하고 원본 하나의 기존 전사를 읽습니다. 다른 클립을 선택해도 앞선 문서가 바뀌지 않는지 확인합니다.
2. 전사가 없는 클립에서 읽기만 누르면 생성하지 않는지, 새 전사 버튼에서만 생성이 시작되는지 확인합니다.
3. 허용한 테스트 파일로 Helper 전사·취소를 확인합니다. HTTPS 인증서 신뢰는 설치 환경에서 별도로 확인합니다.
4. 편집본의 알려진 첫 대사와 내보낸 SRT/VTT 시각을 비교하고, Premiere에서 직접 가져와 재생합니다.
5. 교정·분할·병합 후 JSON으로 저장해 패널을 다시 로드하고 문서를 열어 원본·이력이 보존되는지 확인합니다.
